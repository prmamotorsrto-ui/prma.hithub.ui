Connect the second device quickly

One-time setup (about 10 minutes, free)

  1. Open console.firebase.google.com → sign in with Google → Add project (name it e.g. joan-travels; Google Analytics can be off).
  2. Left menu Build → Realtime Database → Create Database → pick the nearest location (Singapore) → start in test mode.
  3. Open the Rules tab, paste the rules below and press Publish.
  4. Copy the database address shown at the top of the Data tab (starts with https://… and ends with firebaseio.com or firebasedatabase.app) and paste it above → Connect & Sync.
  5. On the mobile: open this same software, go to Sync, paste the Setup Code → Apply Code.

Rules (simple): anyone who knows your database URL could read the bookings, so keep the URL private.

{ "rules": { "joanTravels": { ".read": true, ".write": true } } }

Mobile tip: the mobile needs to open the software file too. Easiest is to put the HTML file online for free (e.g. drag-and-drop it on app.netlify.com/drop or use Firebase Hosting) and open that link on both laptop and mobile – then add it to the phone home screen.
